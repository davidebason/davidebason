# Davide Bason

Physicist (PhD), former postdoc at Tsinghua University, turning to data.

## Projects

- **[loan-process-mining](https://github.com/davidebason/loan-process-mining)**: where a Dutch bank's loan applications stall, from 31,509 applications in SQL. A third of the waiting is an automatic 30-day timer; shortening it would cost 39.9% of conversions, so the recommendation is to test one extra contact instead.
- **[grid-stress](https://github.com/davidebason/grid-stress)**: when Dutch electricity prices go negative or extreme, and what a business gains by shifting consumption away from the dearest hours: about €23,200 a year per megawatt moved.
